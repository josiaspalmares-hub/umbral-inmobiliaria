# Umbral · inmobiliaria (proyecto de muestra)

Web de una inmobiliaria ficticia en el este de Caracas, hecha para el portafolio de Josías Palmares.
Publicada en https://umbral-caracas.vercel.app

- **Mírala crecer:** video de la obra (Gemini) que avanza con el scroll, de la excavación a la torre terminada al atardecer.
- **Elige tu piso:** la torre gira sola (dos tomas de dron unidas) y el piso elegido se marca encima en cada ángulo;
  ficha del apartamento con plano 3D, fotos, distribución y calculadora de inicial y cuotas.
- Propiedades disponibles con ficha, fotos y favoritas; precio por m² por zona; formulario para vender; contacto.

Hecho con React, TypeScript, Vite y Tailwind CSS 4. Torre, interiores y videos generados con Gemini; propiedades con fotos de Pexels; mapas de OpenStreetMap; tasa del BCV
de ve.dolarapi.com.

```bash
npm install
npm run dev
npm run build
```
