# Umbral · inmobiliaria (proyecto de muestra)

Web de una inmobiliaria ficticia en el este de Caracas, hecha para el portafolio de Josías Palmares.
Publicada en https://umbral-caracas.vercel.app

- Buscador en la portada (comprar/alquilar, zona, habitaciones, precio) y propiedades con ficha, fotos, mapa y
  favoritas guardadas en el teléfono.
- Torre Umbral en preventa: torre en 3D (Three.js) donde eliges piso y apartamento, ves su plano isométrico y
  calculas inicial y cuotas. En teléfonos lentos o con "menos movimiento" se muestra un dibujo en SVG.
- Precio por m² por zona, formulario para vender o alquilar (valida y arma el mensaje de WhatsApp), cómo trabajamos,
  equipo, preguntas y contacto.

Hecho con React, TypeScript, Vite, Tailwind CSS 4 y Three.js. Fotos de Pexels; mapas de OpenStreetMap; tasa del BCV
de ve.dolarapi.com.

```bash
npm install
npm run dev
npm run build
```
